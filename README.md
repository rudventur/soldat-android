# 🔫 Soldat Android

A home for one wish: **play Soldat on an Android phone.**

[Soldat](https://soldat.pl) is a fast 2D side-view shooter that people have played for many years. Today there is no ready Android version. This repository is where we plan, track and (step by step) build one.

It is part of the popcorn world on [rudventur.com](https://rudventur.github.io/RudVentur.com/): there is a 🔫 Soldat Android icon in the popcorn launcher that shows the progress from this repository.

## Status

**Planning stage. Nothing runs on a phone yet.**

- 📋 The plain-words plan, with honest size guesses: [PLAN.md](PLAN.md)
- ✅ The progress list: [STATUS.md](STATUS.md) (made from [status.json](status.json), which the popcorn launcher reads)

## What this repository will contain

- Notes, plans and the progress list (today).
- Build scripts and small patches that turn the open source Soldat client into an Android app (later).
- Never the game's own data files or finished game binaries copied from somewhere else. We build from the official source.
